🛠 [Mocklets] — https://mocklets.com

📌 Về gì:
Mocklets là một công cụ mô phỏng API dựa trên HTTP, giúp bạn có thể tạo ra các endpoint giả lập nhanh chóng để phát triển và test API mà không cần đợi backend hoàn thiện. Nó thuộc nhóm công cụ API testing và mocking, đặc biệt hữu ích khi các bạn làm việc theo hướng phát triển song song (parallel development). Điểm nổi bật là giao diện thân thiện, dễ cấu hình và hỗ trợ mock dynamic responses với biến thiên theo request.

🎁 Free tier bao gồm:
• Unlimited mocks với số lượng request không giới hạn hàng tháng  
• 100GB bandwidth miễn phí  
• Custom paths và query params  
• Hỗ trợ CORS và webhook  
• Có sẵn HTTPS với SSL miễn phí  
• Không giới hạn số lần sử dụng hay số dự án  

💡 Phù hợp để dùng khi:
• Khi bạn đang xây API client (frontend/mobile app) nhưng backend chưa sẵn sàng hoặc chậm trễ  
• Khi cần thiết kế API theo đúng spec trước khi implement, để cùng team thiết kế và test  
• Khi muốn test ứng dụng với các trường hợp đặc biệt như error responses, slow API, hay random data mà không ảnh hưởng đến server thật

⚠️ Cần biết trước khi dùng:
• Free tier không giới hạn thời gian nhưng nếu traffic vượt quá 100GB/tháng thì có thể bị giới hạn hoặc yêu cầu nâng cấp  
• Một số tính năng nâng cao như webhook verification, proxy routing mới là các tính năng trả phát (pay-as-you-go)  
• Không phải là thời gian lưu trữ logs hay analytics chi tiết cho tương tác API
