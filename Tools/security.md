## Active Directory B2C
> Thêm vào: 2026-08-04

🎲 Tool random hôm nay!
📂 Major Cloud Providers

🛠 [Active Directory B2C] — https://azure.microsoft.com/services/active-directory/external-identities/b2c/

📌 Về gì:
Active Directory B2C là dịch vụ quản lý danh tính và truy cập (Identity and Access Management) của Microsoft Azure, thuộc nhóm công cụ xác thực người dùng (Authentication). Tool này giúp các developer dễ dàng triển khai hệ thống đăng nhập, đăng ký tài khoản và quản lý quyền cho người dùng cuối (bạn/hạn chế), đặc biệt là các ứng dụng web và mobile. Điểm khác biệt chính so với các tool tương tự như Auth0 hay Firebase Authentication là sự tích hợp sâu với các dịch vụ khác của Azure và khả năng tùy chỉnh hoàn toàn quy trình xác thực thông qua các chính sách (policies).

🎁 Free tier bao gồm:
• 50,000 người dùng được lưu trữ hàng tháng (monthly stored users)
• Không giới hạn số lần đăng nhập hoặc đăng ký (sign-up/sign-in transactions) trong giới hạn 50K user
• Có hỗ trợ SSL miễn phí cho các ứng dụng web
• Có thể tích hợp với các nhà cung cấp bên ngoài như Google, Facebook, Microsoft để đăng nhập (social identity providers)
• Có thể tùy chỉnh giao diện đăng nhập bằng Custom Policies (giới hạn số lần tùy chỉnh cụ thể)

💡 Phù hợp để dùng khi:
• [Ứng dụng web/mobile cần đăng ký tài khoản và đăng nhập cho người dùng cuối] – Bạn đang phát triển một trang web thương mại điện tử hoặc ứng dụng cần quản lý tài khoản người dùng, AD B2C cung cấp giải pháp xác thực mạnh mẽ mà không cần tự xây phức hợp backend.
• [Dự án cần tích hợp đăng nhập bằng tài khoản mạng xã hội như Google/Facebook] – Bạn muốn người dùng có thể đăng nhập nhanh bằng tài khoản hiện có, AD B2C hỗ trợ tích hợp liền mạch với các nền tảng này.
